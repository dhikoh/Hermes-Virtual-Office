# Hermes3D Patch Notes

## Patch v1.0.6 - Camoufox Anti-Detect Browser & VPS / Coolify Headless Infrastructure
- **Feature (Camoufox Anti-Detect Stealth Engine)**: Integrated official `camoufox` (`v0.5.8`) and `playwright-core` into `server/research/browser-service.js`. Provides automated browser fingerprint randomization, WebGL/canvas spoofing, and Cloudflare/bot mitigation designed specifically for AI agent web navigation without bot detection.
- **Feature (Persistent Browser Profile Isolation per Agent)**: Implemented `getAgentProfileDir(agentId)` and `listAgentProfiles()`. Each agent and sub-agent maintains its own persistent profile (`_AI/browser-profiles/<agentId>`) via Playwright's `userDataDir`. Allows operators to assist with manual logins and session cookie retention, enabling autonomous persistent access for agents over time.
- **Feature (Transparent Multi-Tier Fallback)**: Implemented graceful degradation: when Camoufox binary is installed (e.g. VPS/Docker), the browser uses Camoufox; when the binary is absent (e.g. lightweight local testing or offline environments), `fetchIsolatedPage` seamlessly falls back to isolated cookie-free Node HTTP/HTTPS transport without throwing or crashing.
- **Docker & Coolify Production Hardening**: Updated `Dockerfile` runner stage to include all Linux Firefox runtime dependencies (`xvfb`, `libgtk-3-0`, `libasound2`, `libx11-xcb1`, `libdbus-glib-1-2`, `libxtst6`, `libxcomposite1`, `libxdamage1`, `libxrandr2`, `libxfixes3`, `libpango-1.0-0`, `libatk1.0-0`, `libatk-bridge2.0-0`, `libcups2`, `libdrm2`, `libgbm1`). Pre-creates `/root/.camoufox` profile directories and runs `npx camoufox fetch` during Docker build for seamless zero-config Coolify deployment.
- **Gateway RPC & HTTP Status Endpoints**: Added `browser.status`, `browser.profiles.list`, and `browser.navigate` to gateway WebSocket methods, plus HTTP REST endpoints `GET /api/browser/status` and `GET /api/browser/profiles` in `server/hermes-gateway-adapter.js`.
- **UI/UX Enhancement**: Updated `AgentSettingsPanel.tsx` under Capabilities to display the "Camoufox Anti-Detect" badge and clear description of isolated agent profiles under Web Access settings.
- **Comprehensive Automated Testing**: Added unit test suites `tests/unit/camoufoxAdapter.test.ts` (4 tests) and expanded `tests/unit/vaultAndBrowser.test.ts` (9 tests) verifying engine probing, profile path isolation, domain allowlist enforcement, and graceful fallback behavior. Zero TypeScript errors (`tsc --noEmit`), zero ESLint errors.

Automatically consolidates and synchronizes all past sessions to the canonical user profile directory, ensuring no conversation history is ever partitioned or lost across drives or terminals.

All 7 unit test suites (39 tests) pass cleanly with Vitest. TypeScript verified with zero errors (`tsc --noEmit`). ## Patch v1.0.4 - Master Blueprint v2.3.1 Capabilities & Safety Architecture
- **Feature (4-Tier Permission Gate with Deny-Wins)**: Implemented `server/security/permission-gate.js` categorizing all agent actions into 🟢 Green (auto-approved safe reads), 🟡 Yellow (logged workspace mutations), 🔴 Red (human-approved destructive commands / non-allowlisted network queries), and ⚫ Black (absolute hard-block for `.env`, credentials, `.ssh`, browser cookies, and direct writes to `.git/`). Employs strict path normalization and path traversal attack prevention. Verified by `tests/unit/permissionGate.test.ts` (16 tests).
- **Feature (Role Capability Matrix)**: Implemented `server/roles/role-matrix.js` establishing strict tool and resource boundaries across 5 virtual employee roles (`pm`, `developer`, `researcher`, `qa`, `writer`). PM cannot read raw source code or run shell; Developer is isolated from external browsing; Researcher cannot access workspace files or run shell; QA browser access is strictly locked to `localhost`.
- **Feature (Pre-Mutation Snapshots & 1-Click Rollback)**: Implemented `server/workspace/snapshot-manager.js` creating pre-mutation backups under `.hermes/snapshots/` before any file write. Captures file manifests with SHA256 hashes. Supports instant 1-click rollback restoring original files and purging newly added files. Verified by `tests/unit/snapshotManager.test.ts` (3 tests).
- **Feature (Shell / CLI Execution Tool & Approval Ticket Loop)**: Implemented `server/execution/shell-executor.js` with output timeouts, 128KB buffer truncation, and approval ticket lifecycle for Red tier commands. Emits `exec.approval.requested` events over WebSocket. Integrated into `OfficeScreen.tsx` and `AgentChatPanel.tsx` with interactive `ExecApprovalCard` resolution (`allow-once`, `allow-always`, `deny`). Verified by `tests/unit/shellExecutor.test.ts` (5 tests).
- **Feature (Isolated Browser Service & Obsidian Knowledge Vault)**: Implemented `server/research/browser-service.js` (isolated HTTP scraper without user cookies, enforcing domain allowlists) and `server/vault/vault-manager.js` (Obsidian-compatible `_AI/` hierarchy with structured YAML frontmatter tracking trust and author attribution). Verified by `tests/unit/vaultAndBrowser.test.ts` (5 tests).
- **Architecture & Gateway RPC Integration**: Extended `server/hermes-gateway-adapter.js` with 8 agent tools (`workspace_map`, `read_file`, `write_file`, `execute_command`, `web_search_and_read`, `save_research_note`, `list_snapshots`, `rollback_workspace`) and 6 new RPC methods (`exec.approvals.get`, `exec.approval.resolve`, `workspace.snapshots.list`, `workspace.rollback`, `vault.documents.list`, `roles.matrix.get`). Verified by `tests/unit/gatewayNewCapabilities.test.ts` (4 tests).
- **Verification & Quality Assurance**: 100% of new unit tests passed (33/33 tests). Zero TypeScript errors (`tsc --noEmit`), zero ESLint errors, clean end-to-end WebSocket communication.

## Patch v1.0.3 - Real-Time Model Sync & Per-Agent Dynamic Assignment
- **Feature (Real-Time Model Synchronization)**: When activating an API Provider in `ApiSettingsModal.tsx`, the adapter immediately invalidates cached models, fetches the latest model list from the new endpoint (`fetchHermesModels()`), auto-selects a valid default model, persists `HERMES_MODEL` to `.env`, and returns the model catalog in the `config.update` response.
- **Feature (Client-Side Model Hot-Reload)**: Connected `onProviderActivated` callback between `ApiSettingsModal.tsx` and `OfficeScreen.tsx`. Activating a provider immediately pushes the new models into the client state (`gatewayModels`), refreshing the Chat Panel dropdown instantaneously without requiring a page reload or gateway reconnect.
- **Bug Fix & Improvement (Automatic Agent Model Migration)**: In `OfficeScreen.tsx`, agents assigned models that do not exist in the newly selected provider's catalog are automatically migrated to the provider's valid default model, preventing obsolete fallback model displays (e.g., lingering `hermes/nvidia/nemotron-3.5-lightning:free` when switching to custom providers like `trustisgold.web.id`).
- **Feature (Flexible Multi-Agent Model Assignment)**: Clarified and streamlined multi-agent model assignment. Different agents can independently select any model available under the active provider, or all agents can share the same default model without conflicts.
- **Full Verification & Quality Assurance**: All 188 unit test suites (1245 tests) pass cleanly with Vitest. TypeScript compilation verified with zero errors (`tsc --noEmit`). Verified live bidirectional gateway synchronization and `.env` persistence on `ws://localhost:18789`.
